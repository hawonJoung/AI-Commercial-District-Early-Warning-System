# 🏙️ AI 기반 부산 상권 조기경보 시스템(AI-Commercial-District-Early-Warning-System) 

---

## 📌 프로젝트 개요

> **"어떤 상권이 미래에 위축될 가능성이 높은가?"**

`본 프로젝트는 부산광역시 공공데이터를 활용하여 행정동 단위 상권의 소비 구조를 분석하고, 미래 상권 위축 위험을 조기에 탐지하는 머신러닝 기반 조기경보 시스템 구축을 목표로 진행되고 있다.`

`단순히 현재 매출 규모를 분석하는 것이 아니라, 업종 구성과 소비 패턴이 미래 상권 성장 및 위축에 어떠한 영향을 미치는지 탐색하고자 하였다.`

`특히 K-Means 군집분석과 Random Forest 분류 모델을 결합하여 상권 유형을 분류하고, 향후 6개월 뒤 상권 위축 가능성을 예측하는 데이터 기반 의사결정 체계를 구축하는 데 초점을 두고 있다.`

`특히 변수 엔지니어링, 모델 성능 개선, 외부 경제 변수 반영, 위험도 산출 방식 등에 대한 추가 연구가 진행되고 있다.`

## 📊 분석 프로세스

### 1. 데이터 수집 및 전처리

`부산광역시 공공데이터를 활용하여 행정동 단위 소비 데이터를 구축하였다.`

* `행정동별 월평균 매출`
* `업종별 매출 비중`
* `소비 구조 관련 파생 변수 생성`
* `결측치 및 이상치 처리`

---

### 2. 상권 유형 군집화 (K-Means)

`행정동별 소비 특성을 기반으로 유사한 상권을 군집화하였다.`

#### 활용 목적

* `상권 구조 유형 분류`
* `행정동 특성 파악`
* `예측 모델 입력 변수 생성`

#### 주요 과정

* `변수 정규화`
* `유클리드 거리 계산`
* `K-Means 기반 군집 생성`

---

### 3. 미래 상권 위축 예측 모델 구축

`Random Forest 분류 모델을 활용하여 6개월 후 상권 위축 여부를 예측하였다.`

#### 예측 목표

* `정상(0)`
* `위축(1)`

#### 타겟 정의

`미래 성장률(6개월 후 매출 / 현재 매출 - 1)이 0 미만인 경우를 위축으로 정의하였다.` :contentReference[oaicite:1]{index=1}

#### Random Forest 선정 이유

* `비선형 관계 학습 가능`
* `과적합 감소 효과`
* `변수 중요도 제공`
* `해석 가능성 확보`

---

### 4. 모델 성능 평가

`분류 모델의 성능을 다각도로 검증하였다.`

| 지표 | 결과 |
|--------|--------|
| `Accuracy` | 0.73 |
| `Precision` | 0.63 |
| `Recall` | 0.80 |
| `F1-score` | 0.70 |

`특히 Recall(재현율)이 0.80으로 나타나 실제 위험 상권을 사전에 탐지하는 조기경보 시스템 관점에서 양호한 성능을 확인하였다.` :contentReference[oaicite:2]{index=2}

### 5. 상권 위험도 분석

`모델이 산출한 위축 확률을 기반으로 행정동별 위험도를 분류하였다.`

#### 위험도 구간

* `위험 (80% 이상)`
* `주의 (60~79%)`
* `보통 (40~59%)`
* `안정 (40% 미만)`

#### 분석 대상

* `총 205개 행정동`

#### 위험군 분포

* `위험 : 41개 동`
* `주의 : 50개 동`
* `보통 : 38개 동`
* `안정 : 76개 동` :contentReference[oaicite:3]{index=3}

### 6. 상권 위축 요인 분석

`Random Forest 변수 중요도와 그룹 비교 분석을 통해 상권 위축의 주요 요인을 도출하였다.`

#### 주요 변수

* `총 매출 규모`
* `교육 업종 비중`
* `자동차 업종 비중`
* `의료 업종 비중` :contentReference[oaicite:4]{index=4}

#### 핵심 인사이트

* `위험군은 안정군 대비 매출 규모가 크게 나타남`
* `교육 업종 비중이 낮을수록 위험도가 높음`
* `자동차 업종 비중이 낮을수록 위험도가 높음`
* `의료 업종 비중이 높을수록 위험도가 높음`

`이는 특정 업종 편중 현상이 상권 활력 저하와 관련될 가능성을 시사한다.` :contentReference[oaicite:5]{index=5}

### 7. 통계 검증

`위험군과 안정군 간 차이가 우연인지 실제 차이인지 검증하기 위해 독립표본 t-test를 수행하였다.`

#### 검증 변수

* `총 매출 규모`
* `교육 업종 비중`
* `의료 업종 비중`
* `여행 업종 비중`
* `자동차 업종 비중`

`대부분 변수에서 p-value < 0.01 수준의 유의미한 차이가 확인되었으며, 모델이 실제 소비 구조 차이를 학습하고 있음을 확인하였다.` :contentReference[oaicite:6]{index=6}
